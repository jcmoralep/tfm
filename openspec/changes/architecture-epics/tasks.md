Standing rules baked into every task:

- **Lean tests.** Group same-rule cases in `[Theory]`; no reflection-shape tests; no label-by-label tests; keep rule, gate, round-trip and golden tests. Existing goldens (`spec`, `brief`, `prd` rows), `ModuleBoundaryTests`, `FakeArtifactDrafterTests` stay green with no edits beyond those listed.
- **BMAD first.** Follow BMAD 6.12.1 shapes (cite `docs/bmad-referencia.md`). Ideas beyond BMAD (web-verified stack, cascade invalidation) go to `docs/mejoras-posteriores.md`, never into code.
- **Views.** CSS classes only: no `style=`, no `<script>`. Grep every touched razor file.
- **Logs.** Never log document text, PRD/Architecture text, prompts, response bodies or the key. Only ids, type, model, status, duration, `finishReason`, tokens, reason code.
- **Module boundary (D, Testing Strategy).** Artifacts sources forbid `\bConversation\b` and the Initiatives entity token. Prompt literals never contain a capitalised "Conversation", nor "Initiative" not followed by `, ; )`; use the lowercase `<initiative>`. No Assistant-module file changes.
- **Build and test commands** (every gate): `dotnet restore --ignore-failed-sources -p:NuGetAudit=false -p:WarningsNotAsErrors=NU1507`, then `dotnet build -c Release --no-restore` (zero code warnings), then `dotnet test -c Release --no-build`.
- **Final user decisions (2026-10-14), recorded:** (1) a stale upstream stays advisory: an amber hint on the document page, never blocking, never cascading (D3); (2) re-approving the PRD may leave Architecture/Epics Approved-but-stale, and a Large initiative can still complete (design Open Question 1 accepted); (3) cascade invalidation is recorded in `docs/mejoras-posteriores.md` (task 6.9), not built.
- **After apply.** A manual 3-lens code review and an independent verify run outside these tasks' commits.
