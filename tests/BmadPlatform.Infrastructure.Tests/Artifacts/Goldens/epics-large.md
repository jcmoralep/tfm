# Épicas e historias: Consulta de pedidos

## Resumen

- Este borrador divide el trabajo del PRD aprobado en épicas e historias, para que el equipo de desarrollo lo revise y lo construya historia por historia.
- Épicas: 1; historias: 5; requisitos funcionales con historia: 5 de 5.
- [ASSUMPTION: A-1] Esta primera versión propone una historia por cada requisito funcional, con un solo criterio de aceptación genérico; el equipo de desarrollo las agrupa y las afina al revisar este borrador.

## Inventario de requisitos

### Requisitos funcionales

- **FR-1**: Buscar un pedido por su número
- **FR-2**: Ver en qué estado está
- **FR-3**: Recibir un aviso cuando cambie
- **FR-4**: Debe integrarse con El sistema de inventario
- **FR-5**: Debe integrarse con El equipo de logística

### Requisitos no funcionales

- **NFR-1**: Debe funcionar desde el celular
- **NFR-2**: No puede mostrar datos de otros clientes

### Requisitos adicionales

- **AD-1**: Debe funcionar desde el celular
- **AD-2**: No puede mostrar datos de otros clientes
